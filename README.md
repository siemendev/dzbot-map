# dzbot map SDK

[![CI](https://github.com/siemendev/dzbot-map/actions/workflows/test.yml/badge.svg)](https://github.com/siemendev/dzbot-map/actions/workflows/test.yml)
[![@dzbot/map](https://img.shields.io/npm/v/@dzbot/map?label=%40dzbot%2Fmap)](https://www.npmjs.com/package/@dzbot/map)
[![@dzbot/map-react](https://img.shields.io/npm/v/@dzbot/map-react?label=%40dzbot%2Fmap-react)](https://www.npmjs.com/package/@dzbot/map-react)

Interactive DayZ maps for any website — the SDK behind [map.dzbot.de](https://map.dzbot.de).

- [`map/`](map) — `@dzbot/map`, the engine: tiles, pan and zoom, shapes, GeoJSON, controls, drawing tools
- [`map-react/`](map-react) — `@dzbot/map-react`, React bindings

Documentation, live examples and the embed builder: **https://developers.dzbot.de/map/**

This is the code dzbot runs on its own maps. Issues and pull requests are welcome; npm releases are tagged `vX.Y.Z`. See [CONTRIBUTING.md](CONTRIBUTING.md).
